# Research Questions

This research aims to design and evaluate a software engineering framework for
predicting and diagnosing failures in embedded infotainment (IVI) systems using
log-based analysis. The following research questions are formulated to guide the
study.

## Main Research Question (MRQ)
**MRQ:**  
How can a log-based software engineering framework be designed to effectively
predict and diagnose failures in embedded infotainment systems under industrial
constraints?

## Research Question 1 (RQ1)
**RQ1:**  
What types of logs and log characteristics are relevant for failure prediction
and diagnosis in embedded infotainment systems?

*Focus:* Log taxonomy, structure, severity levels, and event semantics.

## Research Question 2 (RQ2)
**RQ2:**  
How can log data be preprocessed and analyzed to extract meaningful patterns
associated with software failures in embedded IVI systems?

*Focus:* Log parsing, feature extraction, pattern mining, and noise reduction.

## Research Question 3 (RQ3)
**RQ3:**  
How can log-based analysis techniques be applied to predict potential failures
before they manifest in embedded infotainment systems?

*Focus:* Predictive modeling, rule-based or machine learning approaches, and
early warning mechanisms.

## Research Question 4 (RQ4)
**RQ4:**  
How can root cause diagnosis be performed using log-based analysis in a manner
that is explainable and useful for embedded software engineers?

*Focus:* Traceability, explainability, fault localization, and diagnostic outputs.

## Research Question 5 (RQ5)
**RQ5:**  
How effective is the proposed framework when evaluated using representative
embedded infotainment log scenarios?

*Focus:* Evaluation metrics, industrial relevance, and validation scenarios.
